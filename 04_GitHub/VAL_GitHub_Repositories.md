# GitHub Repositories for VAL (Vision and AI Lab) - IISc
Directed by Prof. R. Venkatesh Babu

## Dataset Distillation & Knowledge Distillation
*   **Rethinking Dataset Distillation: Hard Truths about Soft Labels (CVPR 2026 Best Paper Finalist)**
    *   *Focus:* Scalability analysis on dataset distillation, examining soft labels and data augmentation.
    *   *Links:* Accessible via [VAL Publications](https://val-iisc.github.io/publications.html).
*   **DeiT-LT: Distillation Strikes Back for Vision Transformer Training on Long-Tailed Datasets (CVPR 2024)**
    *   *Focus:* Distillation framework for training Vision Transformers on long-tailed datasets.
*   **Zero-Shot Knowledge Distillation in Deep Networks (ICML 2019)**
    *   *Focus:* Data-free method to train student models by synthesizing "Data Impressions".
*   **Leveraging Vision-Language Models for Improving Domain Generalization (CVPR 2024)**
    *   *Focus:* Distilling Vision-Language Models (VLMs) to student models to improve out-of-distribution (OOD) generalization.

## 3D Gaussian Splatting & Novel-View Synthesis
*   **Turbo-GS (CVPR 2026 Highlight)**
    *   *Focus:* Accelerating the 3D Gaussian fitting process for high-resolution radiance fields using convergence-aware budget control.
    *   *Repository:* [inspirelt/Turbo-GS](https://github.com/inspirelt/Turbo-GS)
*   **UniC-Lift**
    *   *Focus:* Unified framework for 3D instance segmentation integrating contrastive learning with Gaussian primitives.
    *   *Repository:* [val-iisc/UniC-Lift](https://github.com/val-iisc/UniC-Lift)
*   **ChromaDistill**
    *   *Focus:* Colorizing monochrome radiance fields (including 3D Gaussian Splatting) using knowledge distillation.
    *   *Repository:* [val-iisc/ChromaDistill](https://github.com/val-iisc/ChromaDistill)
*   **AdaptiveSplat (ECCV 2026)**
    *   *Focus:* Texture-aware controllable 3D Gaussian allocation for feed-forward reconstruction.
